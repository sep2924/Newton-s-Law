# Physics Detective

A single-page practice game for Engineering Physics 1 (Newton's laws, ropes, pulleys, inclines).
Everything is in `index.html`; there is no build step.

## Deploy on Render
1. Push this folder to a GitHub repository.
2. In the Render dashboard choose New > Static Site and connect the repository.
3. Leave the build command empty and set the publish directory to `.`
   (or choose New > Blueprint, which reads `render.yaml`).
